Install

From listing to groomed fur in three steps.

  1. Add the listing

    Click Add to VCC, or paste {{ listingInfo.Url }} into Settings ▸ Packages ▸ Add Repository. Then add the package to your avatar project.

  2. Drag your mesh in

    Open Tools ▸ Fur Grooming Tool. The UV layout is generated for you as the paint background. Point it at your lilToon material.

  3. Comb, then save

    Paint flow, length and alpha. Hit save and the maps export and attach to the material.
